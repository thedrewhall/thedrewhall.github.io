# drewhall-site

Static portfolio site. Plain HTML/CSS/JS, no build step.

## Files
- `index.html` — all content
- `styles.css` — styling
- `main.js` — mobile menu, header border on scroll, footer year
- `.nojekyll` — tells GitHub Pages to serve files as-is
- `CNAME` —  for domain hosting
- `apple-touch-icon.png` — favicon for iPhone
- `favicon-32.png` — favicon 32 pixels
- `favicon.svg` - favicon
- `headshot.jpg` - personal headshot for website
